# Rosa Viva

Site educativo estático sobre câncer de mama, criado para o Outubro Rosa. Reúne informações sobre sinais de alerta, fatores de risco, rastreamento e prevenção, um quiz de 10 perguntas e um ranking local.

## Conteúdo

- `index.html` — início
- `informacoes.html` — o que é o câncer de mama e fatores de risco
- `sinais-prevencao.html` — sinais de alerta e redução de risco
- `rastreamento.html` — rastreamento, investigação de sintomas e acesso ao SUS
- `mitos-verdades.html` — mitos e verdades
- `quiz.html` — quiz com 10 perguntas e feedback educativo
- `ranking.html` — ranking salvo apenas no navegador
- `fontes.html` — referências oficiais
- `assets/` — CSS, JavaScript, logo provisória

## Rodar localmente

Não há build nem dependências. Basta servir a pasta como arquivos estáticos:

```bash
python -m http.server 8000
```

Depois abra <http://localhost:8000>.

Também é possível abrir `index.html` diretamente no navegador, mas um servidor local é recomendado para testar o comportamento completo.

## Publicar

O projeto funciona em qualquer hospedagem estática (Netlify, Cloudflare Pages, GitHub Pages). Envie a raiz do repositório sem etapa de build. Para Netlify, publicar a pasta do projeto já é suficiente; não é necessário configurar comando de build.

## Dados e privacidade

- Nenhum dado é enviado a servidores.
- O tema escolhido fica em `localStorage` na chave `rosaviva.tema`.
- Os resultados do quiz ficam em `localStorage` na chave `rosaviva.ranking.v1`.
- O ranking é local ao navegador/dispositivo, não global.
- O apelido do ranking é opcional; não são solicitados dados pessoais ou de saúde.

## Observações

- A logo em `assets/logo-placeholder.svg` é provisória e deve ser substituída pela arte final.
- O conteúdo é educativo e não substitui consulta, exames, diagnóstico ou tratamento profissional.
- Referências principais: INCA e Ministério da Saúde (Nota Técnica nº 626/2025).
